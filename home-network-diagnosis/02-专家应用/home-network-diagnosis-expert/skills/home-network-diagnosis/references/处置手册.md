# 家庭网络诊断：处置手册

按「根因落在哪一层」组织修复步骤。先定位（见《诊断方法论与解读》的同步/异步抖动判定、Bufferbloat 评级、丢包判定），再套用对应层级的动作。所有修复按「本机 → 路由器 → 运营商」由近及远推进。

---

## 一、本机层（用户自己能立刻做）

1. **清理浏览器缓存**
   - 工具内点「🧹 清理浏览器缓存」按钮（清 Cache Storage + 注销 Service Worker）。
   - 注意：这清不掉 DNS 缓存、路由器缓存——后者需在系统/路由器侧处理。
2. **排查占带宽设备**：NAS 同步、大文件下载/BT、视频通话、家人设备大流量最易触发抖动。测速或卡顿时先暂停这些。
3. **关闭本机危险服务**：若本地扫描发现 `3306/5432/6379/9200/27017/3389/5900/8888` 开放且非必要，在防火墙/服务配置中禁用（例如 `brew services stop mysql`、关 Redis 外网监听、关远程桌面）。
4. **WebRTC 防泄漏**：若你靠代理/VPN 隐藏真实 IP 却仍被 WebRTC 暴露，需在浏览器禁用 WebRTC 或装防泄漏扩展（如 WebRTC Leak Prevent / 浏览器 flag `webrtc.ip_handling_policy`）。
5. **以 HTTPS 访问本工具并启用 DoH**：避免流量被劫持；浏览器设置里开启加密 DNS（DoH）。

---

## 二、路由器层（最有效，多数卡顿的根源）

6. **重启光猫 + 路由器**：清除 NAT 会话表/内存泄漏，绝大多数间歇性抽风可解决。先拔光猫等 30s 再插，稳定后再重启路由器。
7. **直连光猫复测（定位金标准）**：
   - 用网线直连光猫（跳过路由器）再点「重新检测」。
   - 抖动/丢包**消失** → 问题在路由器。
   - 抖动/丢包**仍在** → 问题在运营商侧（或光猫本身）。
8. **开启 QoS / SQM（智能队列）**——缓解 bufferbloat 与同步抖动**最有效的本地手段**：
   - 现象：Bufferbloat 评级 C/D/F，或「同步抖动>25%」。
   - 操作：登录路由器管理页 → 找到「QoS / 智能队列 / SQM / 带宽控制」→ 开启并填入运营商给的上下行速率（填实际速率的 90% 左右效果最佳）。
   - 适用固件：OpenWrt（luci-app-sqm）、华硕 Merlin、小米/华为部分机型、路由器系统的「游戏加速 / 智能限速」。
9. **WiFi 优化（若延迟高但直连正常）**：
   - 靠近路由器，或改用 **5GHz** 信道（2.4GHz 易干扰）。
   - 路由器后台把 2.4G 信道固定到 1/6/11 中非拥挤的一个；5G 选 36/149 等。
   - 密集小区可开「双频合一」但卡顿时建议分离。
10. **DNS 改公共 DNS（让全家生效）**：路由器 WAN/DHCP 设置里主 DNS `119.29.29.29`（腾讯）、备 `114.114.114.114`。优于在单台设备改。
11. **开启 IPv6 拨号**：光猫/路由器开启 IPv6（DHCPv6 / SLAAC），IPv4 抖动时可自动走更优路径。

---

## 三、运营商层（直连光猫仍异常时）

12. **报修话术（提高受理率）**：
    - 不要只说「网速慢」。描述为：**「延迟抖动大、有尖峰、不丢包、多人/跑大流量时卡顿缓冲」**。
    - 提供证据：把本工具导出的诊断报告（含同步比例、Bufferbloat 评级、各节点延迟）发给装维。
13. **确认套餐速率与限速**：问清签约上下行；排除被限速、账号异常、光衰过大（光猫光功率应在 −8 ~ −25 dBm 之间，过低需上门）。
14. **光猫桥接 + 自有路由器**：若光猫自带路由性能差（常见），改桥接模式由高性能路由器拨号，往往立竿见影。

---

## 四、Clash / Mihomo 安全加固（若本地检测出现高危）

15. **设 secret**：配置里加 `secret: "强随机串"`，所有控制接口需鉴权。
16. **仅监听 127.0.0.1**：`external-controller: 127.0.0.1:9090`，不要绑 `0.0.0.0`；若需局域网控制用 `allow-lan: true` 但务必配 secret。
17. **换高位端口 + 升级核心**：避免 9090/9097 等默认端口；保持 Mihomo/Clash 核心为较新版本。
18. **全球暴露自查**：用工具内 FOFA/Shodan/ZoomEye 链接，搜 `body="hello:mihomo/clash"` 或端口 9090/9097，确认自己名下资产未暴露；发现暴露立即按 15–17 加固。

---

## 五、路由器安全自查（引导用户自执行，Agent 不代登后台）

诊断尾声可顺手做一次路由器侧安全检查。**以下操作一律由用户自己在路由器后台/官方 App 完成，Agent 只给步骤、不代登录、不触碰凭据**（见《SKILL》权限红线）。

19. **查蹭网设备（陌生连接）**：
   - 进路由器管理页 / 官方 App →「已连设备 / 终端管理」。
   - 核对 MAC/设备名，发现不认识的设备 → 一键拉黑 / 修改 WiFi 密码（用 WPA2/WPA3，别用 WEP）。
20. **改管理密码（别留出厂态）**：
   - 路由器后台「系统 / 管理员设置」→ 把默认 admin/admin 改成强密码。
   - 若支持「禁止 WAN 口管理」，开启后外网无法登后台。
21. **查固件更新**：
   - 后台「系统 / 固件升级」检查并更新到最新；老旧固件有已知漏洞，是家庭网络常被忽视的风险点。
22. **（可选）关 WPS / UPnP**：
   - WPS 易被爆破，非必需建议关闭；UPnP 按需开，长期暴露可关。

## 六、常见现象 → 根因 → 首选动作 速查

| 现象 | 关键证据 | 首选动作 |
|------|----------|----------|
| 看视频/打游戏间歇卡顿缓冲 | 同步抖动>25% 或 Bufferbloat C/D/F | 路由器开 QoS/SQM |
| 整体慢、Ping 高 | 平均延迟>80ms | 直连光猫复测定位 |
| 偶尔瞬断、连不上 | 丢包率>2% | 重启光猫路由 + 换 5G WiFi |
| 多人同用就卡 | Bufferbloat 评级差 | 开 SQM + 限单设备带宽 |
| 测速远低于套餐 | 下行<10/30 Mbps | 查限速/占带宽设备/直连复测 |
| 担心真实 IP 泄露 | WebRTC 暴露公网 IP | 禁用 WebRTC / 防泄漏扩展 |
| 代理节点被任意网页读 | Clash 无密钥可读 | 设 secret + 绑 127.0.0.1 |
