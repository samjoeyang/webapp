# 诉讼费用交纳标准（速查）

> 依据：《诉讼费用交纳办法》（国务院令第 481 号，2007-04-01 施行）。
> 本表为 calculator.py 的权威依据。截止核验日期：2026-10-29，办法文本以 gov.cn 公布版为准，未见修订。

## 一、案件受理费

### （一）财产案件（按诉讼请求金额/价额分段累计）
| 区间 | 费率/定额 |
|---|---|
| 不超过 1 万元 | 每件 50 元 |
| 超过 1 万至 10 万元 | 2.5% |
| 超过 10 万至 20 万元 | 2% |
| 超过 20 万至 50 万元 | 1.5% |
| 超过 50 万至 100 万元 | 1% |
| 超过 100 万至 200 万元 | 0.9% |
| 超过 200 万至 500 万元 | 0.8% |
| 超过 500 万至 1000 万元 | 0.7% |
| 超过 1000 万至 2000 万元 | 0.6% |
| 超过 2000 万元 | 0.5% |

### （二）非财产案件
- 离婚：每件 50–300 元；涉及财产分割且总额 > 20 万元，超出部分按 0.5%。
- 人格权（姓名权、名称权、肖像权、名誉权、荣誉权等）：每件 100–500 元；损害赔偿 ≤ 5 万不另交，5 万–10 万部分 1%，> 10 万部分 0.5%。
- 其他非财产案件：每件 50–100 元。

### （三）知识产权民事案件
- 无争议金额/价额：每件 500–1000 元。
- 有争议金额/价额：按财产案件标准。

### （四）劳动争议：每件 10 元。
### （五）行政案件
- 商标、专利、海事行政案件：每件 100 元。
- 其他行政案件：每件 50 元。

### （六）管辖权异议不成立：每件 50–100 元。

> 第（二）（三）（六）项由省级政府在区间内自定具体标准（见下表示例）。

## 二、申请费

### （一）申请执行
| 区间 | 费率/定额 |
|---|---|
| 无执行金额/价额 | 50–500 元 |
| 不超过 1 万元 | 50 元 |
| 超过 1 万至 50 万元 | 1.5% |
| 超过 50 万至 500 万元 | 1% |
| 超过 500 万至 1000 万元 | 0.5% |
| 超过 1000 万元 | 0.1% |

### （二）申请保全措施
- ≤ 1000 元或不涉及财产：30 元
- 超过 1000 元至 10 万元：1%
- 超过 10 万元：0.5%
- **上限 5000 元**

### （三）支付令：比照财产案件受理费标准的 1/3。
### （四）公示催告：每件 100 元。
### （五）撤销仲裁裁决 / 认定仲裁协议效力：每件 400 元。
### （六）破产案件：按财产案件受理费标准减半，最高不超过 30 万元。
### （七）海事申请费（区间）：设立责任限制基金 1000–1 万；海事强制令/船舶优先权催告 1000–5000；海事债权登记/共同海损理算 1000。

## 三、减半 / 不交情形
- 调解结案、申请撤诉：减半（第十五条）。
- 简易程序：减半（第十六条）。
- 反诉、有独三合并审理：分别减半（第十八条）。
- 支付令：按 1/3（第十四条第三款）。
- 不交受理费：特别程序、不予受理/驳回起诉/驳回上诉裁定、行政赔偿、再审（法定例外除外）等（第八条、第九条）。

## 四、地方具体标准示例（法定幅度内）
| 项目 | 国家区间 | 贵阳市南明区（2026 涉企收费目录） |
|---|---|---|
| 离婚 | 50–300 | 200 |
| 人格权 | 100–500 | 300 |
| 其他非财产 | 50–100 | 60 |
| 知识产权无争议 | 500–1000 | 800 |
| 管辖权异议 | 50–100 | 60 |

> calculator.py 用 `--locality guiyang_nanming` 套用上表；新增地方标准请在 `LOCALITIES` 字典中追加。

## 五、法院外费用（本 skill 仅作可选估算，不计入法院诉讼费合计）
- **财产保全保险费**：交保险公司，按保全金额 × 0.1%–0.3%（默认取 0.2%）估算。
- **公证费**（交公证处，依据《公证服务价格形成机制指导意见》发改价格〔2021〕1081 号及地方标准，由 `--notary-mode` 选择计算方式）：
  - `evidence` 保全证据公证（知识产权维权取证最常用）：**按件 ¥1000**（默认）。
  - `document` 文书副本/译本与原本相符：**按件 ¥50**。
  - `contract` 合同/协议类：按标的额 **0.3%**（最低 ¥200）。
  - `property` 财产类（继承/赠与/遗赠/财产分割）：按标的额差额累进（最低 ¥200）：

    | 标的额区间 | 费率 |
    |---|---|
    | ≤ 20 万元 | 1.2% |
    | 20–50 万元 | 1.0%（增量） |
    | 50–500 万元 | 0.8% |
    | 500–1000 万元 | 0.5% |
    | 1000 万–1 亿元 | 0.1% |
    | > 1 亿元 | 0.05% |

  - `lump` 直接给定金额（或 `--notary-fee` 手动覆盖，优先于 mode）。
  - 各地公证处收费差异较大，最终以公证处报价为准。

## 六、其他诉讼相关费用（市场化·估算，依据与默认值）
> 以下均非法院收取，金额随地区、机构、案情浮动，本 skill 给出合理公式/默认值，交付时须提示“以实际报价为准”。

### （一）律师费（各省政府指导价中位水平，差额累进 + 基础费下限 5000 元）
| 标的额区间 | 指导价比例（估算） |
|---|---|
| ≤ 10 万元 | 7% |
| 10–50 万元 | 6%（增量） |
| 50–100 万元 | 5% |
| 100–500 万元 | 4% |
| 500–1000 万元 | 3% |
| 1000–5000 万元 | 2% |
| > 5000 万元 | 1% |
- 风险代理：按标的额比例计，累计最高 **18%**；婚姻/继承/请求支付劳动报酬/行政/刑事/国家赔偿等**禁止风险代理**。
- 计件（非财产案件）：按件协商，默认 5000 元起。
- 具体以当地《律师服务收费管理办法》及委托合同为准。

### （二）财产保全责任保险费（/保函费）
- 交保险公司或担保公司，按保全金额 × **0.1%–0.3%**（默认 0.2%）估算。
- 与法院保全申请费（见第二节）是两笔钱：前者交市场机构，后者交法院。

### （三）鉴定费（按件/按比例，区间大）
- 文书/痕迹/笔迹鉴定：约 1000–2000 元/件（默认 1500）。
- 工程造价/质量鉴定、司法会计鉴定：按标的额差额累进（如 100 万内 0.8%、100–500 万 0.5%、以上 0.3%）。
- 以司法鉴定机构报价为准。

### （四）评估费（资产评估，差额累进，floor 1500）
| 资产额区间 | 费率 |
|---|---|
| ≤ 100 万元 | 0.9% |
| 100–1000 万元 | 0.375% |
| 1000 万–1 亿元 | 0.12% |
| 1 亿–10 亿元 | 0.03% |
| > 10 亿元 | 0.008% |

### （五）拍卖费（佣金，差额累进，受《拍卖法》≤5% 成交价约束）
| 成交价区间 | 佣金比例 |
|---|---|
| ≤ 200 万元 | 5% |
| 200–1000 万元 | 3%（增量） |
| 1000–5000 万元 | 2% |
| > 5000 万元 | 1% |

### （六）公告费（法院公告登报）
- 按次/按字数计，常见 300–800 元/次（默认 600）。

### （七）翻译费（涉外）
- 按千字计费，常见 200–500 元/千字（默认 300）。

### （八）差旅费
- 实报实销，由用户/律师实际发生填列，无统一公式。

## 七、于实际发生时另计（无统一公式，仅提示）
- 证人、鉴定人、翻译人员、理算人员出庭发生的交通费、住宿费、生活费、误工补贴（《办法》第十一条）。
- 复制案件卷宗材料和法律文书的工本费。
- 因鉴定、勘验、评估、拍卖、运输、仓储、保管等发生的、由当事人直接支付给有关机构的费用。
