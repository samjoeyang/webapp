## 踩坑：macOS bash 3.2 变量名吸收多字节字符
- `$VAR）`（变量后紧跟中文全角括号）在 macOS 自带 bash 3.2 下会把 `）` 的字节吸收进变量名 → "unbound variable"。所有 bash 脚本变量后跟非 ASCII 时必须用 `${VAR}` 花括号。platform_check.sh 与 wifi_scan.sh 已各修复一处。
