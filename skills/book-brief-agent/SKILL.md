# 精读一书智能体

## 概览

本技能把一本书加工成结构稳定的几分钟精读内容，支持两条素材路线（公开解读 / 全书解析），并先确认内容范围（默认全书；用户明确指定时可只精读单章或多章），按“分块摘要 → 主线合并 → 压缩成稿 → 事实校验”分层蒸馏，定稿后按需接力配音、字幕、分镜配图与视频成片。范围边界与回退规则见 `references/scope-boundary.md`，分镜/画面/合成/终审规则见 `references/storyboard-pipeline.md`。

## WorkBuddy 环境适配（本地补丁）

- 配图用内置 `ImageGen`；视频片段用内置 `VideoGen`（支持文生视频与首帧图生视频）。两者调用前必须告知用户额外积分消耗。
- 当前 WorkBuddy 未提供内置 TTS。若环境无可用文字转语音工具，L2/L3 配音降级为：交付口播稿、SRT 时间轴与静音占位，由用户提供音频后再对齐；不得声称已生成配音。
- 下文及参考文件中 `text_to_audio_plus`、`audio_to_audio_plus`、`image_gen`、`doubao-creative-video`、`byted-mediakit-video` 等工具名来自其他平台，仅在工具真实存在时调用；调用前先发现真实 schema，不臆造参数，不存在时按上述映射降级。

## 节点 0：前置校验（进入主流程前逐条过）

1. **原文件缺失 → 不终止，转平台检索**
   - 用户未上传 EPUB/PDF/TXT/扫描件，或上传文件解析失败、无法读取时，不直接报错退出；转入路线 A，按 `references/source-collection.md` 第 1 节的平台优先级（T1 微信读书/国图/QQ阅读/掌阅/得到/豆瓣阅读 → T2 试读与元数据平台 → T3 公益/特定品类）依次检索该书内容。
   - 检索后仍只有简介/目录、无足够正文支撑成稿时，向用户说明实际可读范围，降级为公开解读稿或由用户决定是否继续；不伪造原文细节。
2. **版权合规 → 先风险提醒，用户坚持则继续**
   - 判定书籍版权/授权状态存疑（如仍在版权保护期、来源为非授权镜像、用户要求大段复述等）时，先按 `references/risks.md` 给出足够明确的风险提醒（来源合规、不可大段复述、对外发布责任等）。
   - 提醒后若交互用户明确仍要求生成，则按用户要求继续；全程仍守住采集边界（只提炼观点/结构/有限引用，不整段复制受保护表达），并在成稿元信息中标注素材路线与来源。
3. **信息不全 → 只补问缺失项，不脑补**
   - 缺书名/作者/目标受众等关键信息时，只针对缺失项提问补齐；不自动猜测书名版本、作者或受众。
4. **默认受众**：普通成年人，通俗但不低幼、非学术深度解读；除非用户手动指定其他受众，否则沿用此默认值。

## 内容范围确认（进入主流程前锁定）

完整规则见 `references/scope-boundary.md`，要点如下：

1. **范围类型**：全书 / 指定单章 / 指定多章；**无特殊说明默认全书**，仅用户明确指定时才限定为局部章节。
2. **边界清单**：书名与版本、选定范围（局部须写章节编号与标题）、一句话主线、目标受众、采集口径；内容严格框定在确认范围内，不擅自拉入未选定部分。
3. **变更回退**：中途改变范围（全书↔单章↔多章、换书/换章），回退到素材采集与文稿重写环节，原有后续产出（摘要、总稿、配音、字幕、分镜、配图、成片）作废；同范围内部文字微调按现有校验规则局部处理。
4. **篇幅适配**：局部章节仍守 8～9 分钟目标、2500 字硬上限；缺内容只在选定素材内补，超量按 P0/P1/P2 取舍。
5. **元卡片字段**：新增【内容范围】，标注全书或具体章节；范围变动同步刷新。
6. **系列视频**：同书分集时每集独立确认范围与主线，全套统一配音与美术风格，单集守篇幅约束，并标注集号与章节范围。

## 开工前判断

1. **素材路线**（见 `references/pipeline-design.md` 第 1 节）
   - 只给书名/作者 → 路线 A：联网搜索，交叉 2 个以上来源；
   - 上传 PDF/EPUB/MOBI/AZW/AZW3/TXT/DOCX/FB2/扫描件 → 路线 B：解析原文，超长文本切块分批处理。
2. **产物级别**（见 `references/video-pipeline.md` 第 1 节）
   - 默认只交付 L1 文字精读稿；用户明确要音频/视频时再逐级向下，不跳过确认直接生成。
3. **可变参数**：目标时长（默认 8～9 分钟，硬上限 2500 字）、语速（默认 220 字/分钟）、口吻、受众、内容范围（默认全书）、重点数量；缺失时用默认值并在成稿前告知用户。

## 主工作流

### 步骤 1：获取素材
- 路线 A：未提供电子书文件时，按 `references/source-collection.md` 的平台优先级（按可读正文量排序，微信读书/国图/QQ阅读/掌阅/得到/豆瓣阅读在前，试读与元数据平台在后，聚合站仅作线索）依次检索；搜索不足时用浏览器读取可见页面，记录来源并多来源交叉。
- 路线 B：读取上传文件；扫描图片先 OCR；长文本先跑切块脚本（见下方脚本清单）。
  - 支持格式：PDF（文字版）、EPUB、MOBI、AZW/AZW3、TXT（UTF-8）、DOCX、FB2、扫描页图片；图片先 OCR 提取文本；Kindle 系格式（MOBI/AZW/AZW3）先转换/解析出纯文本再切块，解析不了按兜底降级。
  - 解析兜底（逐级降级）：加密/损坏/打不开 → 转路线 A 并说明原因；OCR 后有效可读正文不足一半 → 提示更换清晰版本，无替代则转路线 A；编码乱码先尝试 UTF-8/GBK/GB18030 转换，仍乱码按此处理；正文与书名/作者明显不符 → 停住核对版本，不脑补继续。
  - 切块规则：默认 `--max-chars 1500`；先按章节标题切，再在**段落结束边界**切割，保持段落完整，禁止从段落中间硬断；仅当单个段落本身仍超长时，才退到句子边界（。！？；）切。同章被切成 3 个以上小块时，摘要环节先按同章合并摘要，避免结论割裂。切块实际使用的 max-chars 记入任务元信息。

### 步骤 2：分块摘要
按 `references/prompts.md`「分章摘要」模板，逐章/逐块提炼核心论点、案例数据、金句与章节作用；只依据素材，不发挥。

### 步骤 3：主线合并
按「主线合并」模板梳理：核心问题、论证结构、最终结论、关键概念；标出可舍弃的次要分支。

### 步骤 4：压缩成稿
- 套用 `assets/brief_template.md`，按「压缩成稿」模板写成口播稿；
- 篇幅匹配目标时长；成稿末尾附配图/画面建议；
- 跑 `scripts/estimate_duration.py` 校验时长：偏短补案例，偏长砍次要分支。

### 步骤 5：事实校验
按「事实校验」模板对照素材逐条核对：观点是否有依据、有无编造案例/金句、是否把引申当成原意；未命中内容删除或标「存疑待核」。

### 步骤 6：交付定稿
- L1：交付 `brief.md` 与口播纯文本；
- 需要后期时，按 `references/video-pipeline.md` 继续阶段 1~5。

## 后期链路（按需启用）

- **配音风格预审（强制前置）**：按 `references/voice-presets.md` 依题材选定一套锁定音色 profile（性别/年龄感/音色/语速/情绪），方案确认一次后全片复用，中途不换声线。
- **自动配音**：用 `text_to_audio_plus`（有参考音色用 `audio_to_audio_plus`）按分句分段合成，前缀复用同一 profile；再用 `scripts/concat_audio.py` 拼接成一条完整 WAV；调用前先 `tool_search` 获取真实 schema。
- **字幕**：`scripts/script_to_srt.py` 生成 SRT 与分句 JSON；配音完成后以实际音频时长复核对齐。
- **分镜与配图**：按 `references/storyboard-pipeline.md` 执行：先出七字段分镜表对齐音频时间轴，首镜锁定风格基准后再批量续镜；用 `image_gen` 按分镜提示词生成配图，全片色调、写实/插画、画幅统一；单镜头 3～6 秒、硬上限 8 秒。
- **视频生成与合成**：动态片段生成前必须先加载 `doubao-creative-video` Skill 完成参数确认，再调用 `text_to_video` / `image_to_video` / `media_to_video`；图文成片（静态配图+配音+字幕）确认画幅后可自动合成；拼接、字幕压制、转码走 `byted-mediakit-video`。合成以音频时间轴为准，转场克制，节奏与情绪按终审规则推进。
- **终审交付**：按 `references/storyboard-pipeline.md` 第 11 节过内容/技术/风格三审，输出成片并附版本说明；生成失败的镜头标记占位、等待用户确认替换，不强行输出崩坏画面。

详细工具映射、自动化边界、确认点与降级方案见 `references/video-pipeline.md`；分镜与画面链路细则见 `references/storyboard-pipeline.md`。

## 脚本清单

| 脚本 | 用途 |
|---|---|
| `scripts/split_chapters.py` | 长文本按章节/字数切块，输出 chunks.json |
| `scripts/estimate_duration.py` | 按字数估算口播时长，判断是否在目标区间 |
| `scripts/script_to_srt.py` | 口播稿分句，输出 SRT 字幕与 lines.json |
| `scripts/concat_audio.py` | 分段配音下载并无损拼接为一条完整 WAV，输出总时长 |

## 风险底线

对外发布前核对 `references/risks.md`：不大段复述版权原文、不编造书中细节、标注速读解读不替代通读；专业书籍附加“不构成专业建议”提示。
