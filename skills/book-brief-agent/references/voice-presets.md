# 配音风格预设（音色统一规则）

> 本文件是配音前的风格预审依据。定稿后先按题材选定一套预设，锁定为全片唯一的音色 profile；所有分段配音复用同一套描述，避免出现“三段三个声音”的割裂感。

## 目录
1. 音色统一硬规则
2. 题材预设表
3. 预审流程
4. TTS prompt 拼装格式

## 1. 音色统一硬规则

- **一套 profile 走全片**：性别、年龄感、音色质感、语速、情绪、录制环境只确定一次，写成固定前缀串 `VOICE_PROFILE`；每一段 TTS 的 prompt 都拼接同一个前缀，禁止各段单独换描述。
- **分段只切文本，不改声音**：按分句清单切点分段，音色、语速、情绪参数全程不变；段间停顿由文本标点和后期拼接留白控制。
- **生成后抽查**：核对各段声线、语速是否一致；某段听起来明显不同，用同一 `VOICE_PROFILE` 单独重生成该段，再重新拼接。
- **不做真人声纹克隆**：未获授权不使用参考音色复刻真人；用户提供参考音频时才走 `audio_to_audio_plus`，且全片沿用同一条参考。
- **风格必须贴题材**：先判断书籍基调再选预设；沉重题材不用轻快明亮声线，干货题材不用过度煽情语气。

## 3. 预审流程

1. 读定稿成稿，判断题材与基调（对照上表；跨题材时取主基调）。
2. 选定一条预设，写入本次任务的 `VOICE_PROFILE`、语速 wpm、情绪说明；用户有明确偏好（性别、年龄、口音）时覆盖对应字段，其余保持预设。
3. 把预设作为“配音方案”先告知用户：音色、语速、情绪、是否配背景音乐；用户确认或调整后再进入批量合成。用户无特别要求时，按预设直接执行，不再逐段确认。
4. 合成完成后抽查一致性，必要时重生成问题段。

## 4. TTS prompt 拼装格式

每段配音的 prompt 统一按下面结构拼装，`VOICE_PROFILE` 取自第 2 节：

```
{VOICE_PROFILE}，{情绪与语速要求}，在安静室内自然朗读，不要播音腔。朗读以下内容：{本段文本}
```

- 朗读正文永远放在指令末尾，不要只传待读文本。
- 单次生成 ≤120 秒；超长按分句清单分段，每段共用同一前缀。
- 背景音乐不在人声 TTS 内生成；如需配乐，后期单独添加并压低音量衬底。
