# 可复用提示词模板

> 占位符用 `{{变量}}` 标注；实际使用前替换。所有模板默认中文输出。变量不在模板内臆造，素材缺失时先向用户索取或标注存疑。

## 目录
1. 分章摘要
2. 主线合并
3. 压缩成稿（口播）
4. 事实校验
5. 可变参数

## 1. 分章摘要

```
你是一名读书拆解编辑。下面是书籍《{{书名}}》的{{章节定位，如：第一章/切块 N}}原文（或公开资料摘录）：

【素材】
{{chunk_text}}

请只基于以上素材提炼，输出：
- 本章核心论点（1~3 条，每条一句话）
- 支撑论点的关键案例/数据/人物（保留可回溯的细节，注明在素材中的位置）
- 可直接引用的金句（原文照抄，不要改写）
- 本章在全书中的作用（铺垫/论证/转折/收尾）

约束：
- 素材中没有的内容一律不写；不做主观发挥；
- 不评价作者对错，只复述观点；
- 输出为结构化 Markdown，不要寒暄。
```

## 2. 主线合并

```
你是一名主编。以下是《{{书名}}》各章摘要：

【各章摘要】
{{chapter_summaries}}

请合并梳理出全书主线，输出：
- 作者要解决的核心问题（1 句）
- 全书论证结构：分几步推进，每步对应哪些章节
- 最终结论/核心主张（1~3 条）
- 贯穿全书的关键概念清单
- 主线中出现、但成稿可舍弃的次要分支（列出并说明理由）

约束：只使用各章摘要中已有的信息；前后矛盾处标注出来，不要自行抹平。
```

## 3. 压缩成稿（口播）

```
你是一名知识类短视频口播撰稿人。基于以下主线摘要，写一篇 {{目标时长，如 4 分钟}} 口播精读稿：

【主线摘要】
{{main_synopsis}}

要求：
- 结构：开场钩子 → 这本书在讲什么 → 3~5 个重点拆解（每个重点：观点 + 一个案例/比喻）→ 总结与行动启发 → 收尾金句；
- 口吻：{{口吻，如：平实亲切 / 理性克制}}，面向{{受众，如：普通职场人}}；句子短，适合朗读，避免长定语和书面嵌套；
- 篇幅：约 {{目标字数，如 900~1100}} 字（按 240 字/分钟估算，可先用时长脚本校验）；
- 每个重点后标注出处章节，便于核对；
- 只保留主线相关内容，次要分支一律舍弃；
- 不确定或素材未覆盖的点，写成「存疑待核」，不要编造。

输出：先给一句标题，再给口播正文（分段，每段一个意群），最后附「配图/画面建议」列表。
```

## 4. 事实校验

```
你是一名事实核查编辑。请对照原始素材，核查下面这篇精读稿：

【原始素材】
{{source_material}}

【待核查成稿】
{{draft}}

逐条输出核查结果：
- 观点/案例/数据/金句 → 是否能在素材中找到依据（命中/未命中/部分命中）；
- 未命中项：给出处理建议（删除 / 改为存疑标注 / 补充依据）；
- 是否存在把解读者引申当成作者原意的情况；
- 覆盖范围：列出已读块数/总块数（或抽样字符占比）与抽样方式；结论是否超出覆盖范围？超出项删除或降格为「存疑待核」；
- 结构与时长是否达标；列出需要修改的具体句子。

约束：拿不准的一律标「存疑」，不得为了通顺而放行。
```

## 5. 可变参数

| 参数 | 取值示例 | 默认 |
|---|---|---|
| 目标时长 | 3 / 5 / 8 分钟 | 3~5 分钟 |
| 语速 wpm | 200 / 240 / 280 | 240 |
| 口吻 | 平实亲切、理性克制、轻松吐槽、学院派 | 平实亲切 |
| 受众 | 学生、职场人、家长、泛知识读者 | 泛知识读者 |
| 重点数量 | 3 / 5 | 3~5 |
| 输出形态 | 纯文字稿、图文笔记、短视频口播稿 | 口播稿 |
