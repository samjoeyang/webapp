# 研究依据核对

在报告/研究提交前，逐条核对「结论 ↔ 依据」的对应关系，检查口径一致性，并对缺依据项做标准标注。重点是**挑出"结论悬空"和"口径打架"**，而非润色文句。

## 一、名称与说明

**名称**：研究依据核对（Research Evidence Check）

**说明**：把一份研究/报告拆成「结论」与「依据（引用资料、数据、方法）」两栏，逐项核查三件事：

| 核查维度 | 含义 | 典型问题 |
|---|---|---|
| 结论—依据对应 | 每条结论是否能追到具体依据，且依据真正支撑该结论 | 依据说"出货量第二"，结论写"营收第一"（偷换概念）；依据仅限样本 A，结论推广到全体（过度推断）；有结论无出处 |
| 口径一致性 | 多处数据/概念在统计口径与定义上是否统一 | 时间口径不一（2023-08 vs 2024-Q1）；单位/币种混用（亿元 vs 亿美元、人民币 vs 美元）；同一概念定义漂移（"活跃用户"前后标准不同）；样本/地域范围不一致 |
| 缺依据标注 | 无出处、无方法、无法追溯的结论如何规范标注 | 结论没有来源；数据未经说明直接引用；推算过程缺失导致无法复核 |

不触发：用户只要求翻译、改写、排版或纯事实查询且未提「核对/依据/口径」时，正常处理，**不**强制走本流程。

## 二、触发条件

- 用户说「核对依据 / 结论有没有支撑 / 口径一致吗 / 缺依据怎么标 / 研究依据核对 / 论证核查 / 帮我看看结论站不站得住」并附研究材料。
- 用户粘贴含「结论 + 引用资料/数据」的报告、分析、调研、尽调、立项材料，要求把关论证质量。
- 用户提交前要求「先核对依据再定稿」。
- 用户要求对一份材料中"无来源"的结论做统一标注。

## 三、步骤

1. **拆栏建表**：通读材料，把内容拆成"结论"和"依据"两栏。给每条结论编号（C1、C2…），依据标注来源/位置（如「据 CNNIC 第 52 次报告」「内部 2024Q1 数据」）。建立可引用的定位锚点（段落/行号）。
2. **对应性核查**：逐条判断结论与依据的关系，标为四类之一：
   - `对应`：依据直接、充分支撑该结论。
   - `弱对应`：依据相关但偏弱/间接，结论有推断成分。
   - `不对应`：依据与结论错位（偷换概念、方向相反、范围越界、过度推断）。
   - `缺依据`：该结论找不到任何依据或出处。
3. **口径一致性核查**：横向比对所有数据项，检查以下口径是否统一，记录冲突点：
   - 时间口径（统计时点/区间、财年 vs 自然年）
   - 范围口径（样本、地域、人群、业务边界）
   - 单位与币种（亿元/亿美元、RMB/USD、绝对值/占比）
   - 定义口径（同一指标前后定义是否一致）
   - 来源版本（是否同一版报告/同一数据集）
4. **缺依据标注**：对 `缺依据` 与 `弱对应` 项，按下方规范做标准标注（符号 + 缺口说明 + 处置建议）。
5. **收敛输出**：按输出格式生成「对照表 + 口径问题 + 缺依据标注汇总 + 关键风险」。问题项按严重程度（高/中/低）排序，高=结论与依据严重错位或关键结论无依据；中=口径不一致但可修正；低=标注性提示。

### 缺依据标准标注规范

统一使用以下符号，紧跟在有问题的结论之后或汇总于标注表：

| 标注符号 | 适用场景 | 写法示例 |
|---|---|---|
| `〔缺依据〕` | 结论完全无出处/无方法/无法追溯 | `〔缺依据〕下沉市场渗透率达 65%——无来源，建议补充或降级为"据估算"。` |
| `〔弱对应〕` | 有依据但偏弱、存在推断或口径差异 | `〔弱对应〕依据仅覆盖一线城市样本，结论推广至全国存疑。` |
| `〔口径不一致〕` | 同一指标前后口径冲突 | `〔口径不一致〕A 项为 2023-08 数据、B 项为 2024-Q1 数据，不可直接并列比较。` |
| `〔不对应〕` | 依据与结论错位（偷换/越界/反向） | `〔不对应〕依据称"出货量第二"，结论写"营收第一"，概念偷换。` |

标注三要素：**缺什么（数据/出处/方法）→ 为何关键 → 如何处置（补来源 / 降级措辞 / 加限定语）**。不确定时标 `〔待确认〕`，不臆造来源。

### 输出格式

```
【研究依据核对结果】

一、结论—依据对照表
| 编号 | 结论 | 对应依据 | 对应性 | 备注 |
| C1 | … | 据…（位置） | 对应/弱对应/不对应/缺依据 | … |
| C2 | … | — | 缺依据 | … |

二、口径一致性问题（N 项）
1. 〔中〕C1 与 C3 时间口径不一：2023-08 vs 2024-Q1，并列比较需统一时点。
…

三、缺依据标注（N 项）
1. 〔高〕C2 〔缺依据〕"渗透率 65%"无出处——建议补充来源或改为"据估算约 65%"。
…

四、关键风险与建议
- 高风险：C2 无依据却作核心结论，提交前必须补源或弱化。
- 建议：统一时间/单位口径后重排数据表；对 3 处弱对应加限定语。
```

## 四、演示示例（内置 2 条）

**示例 1 — 结论与依据不对应 + 过度推断**

> 结论（C1）：「2024 年 Q1 公司营收已超过行业第二名，稳居市场第一。」
> 依据：「第三方报告显示，公司 2024 年 Q1 出货量同比增长 32%，在品牌出货量排名中位列第二。」

核对结果：
- 对应性：`〔不对应〕`——依据说的是"品牌出货量排名第二"，结论却写成"营收超过行业第二、市场第一"：既把"出货量"偷换为"营收"，又把"第二"说成"第一"，方向与依据相反。
- 缺依据：`〔缺依据〕`——"营收口径市占率第一"无任何来源，属核心结论悬空。
- 建议：删除"营收第一"表述；若需论证市占，须补充营收口径数据；否则将结论收敛为"出货量位列第二、同比增长 32%"。

**示例 2 — 口径不一致 + 缺依据**

> 结论组：
> - C1：「中国短视频用户规模达 10.2 亿。」依据：CNNIC 第 52 次报告（2023-08）。
> - C2：「短视频日均使用时长 120 分钟。」依据：某机构 2024-Q1 调研。
> - C3：「下沉市场渗透率达 65%。」依据：无。

核对结果：
- 口径一致性：`〔口径不一致〕`C1 时点 2023-08 与 C2 时点 2024-Q1 不同，且"用户规模"与"日均时长"为不同定义维度，并列呈现易误导为同一口径；建议统一到同一统计时点与口径再比较。
- 缺依据：C3 `〔缺依据〕`"渗透率 65%"无出处——建议补充来源，或降级为"据估算约 65%"，并在脚注标明推算方法。
- 对应性：C1、C2 依据充分，标 `对应`；C3 标 `缺依据`。

预期命中：示例 1 命中"不对应 + 缺依据"；示例 2 命中"口径不一致 + 缺依据"，验证三维度核查逻辑。

## 五、自检清单

- [ ] 已把材料拆成「结论/依据」两栏并建立定位锚点，未凭片段下结论
- [ ] 每条结论已标对应性（对应/弱对应/不对应/缺依据），未漏判
- [ ] 已横向比对时间/范围/单位/定义/来源版本五类口径，记录冲突点
- [ ] 缺依据项已用标准符号标注三要素（缺什么→为何关键→如何处置）
- [ ] 输出含「对照表 + 口径问题 + 缺依据汇总 + 关键风险」，问题按严重程度排序
- [ ] 未臆造来源；拿不准的标 `〔待确认〕` 而非断言
