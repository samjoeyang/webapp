## 为什么你需要它：微信文件的 4 个坑

1. **找不到** —— 微信把文件按哈希分桶藏在深层目录，肉眼根本翻不动。
2. **打不开** —— 图片、视频被微信加密成 `.dat`，双击全是乱码。
3. **理不清** —— 同一份文件被反复转发，同名不同内容、同内容不同名。
4. **不敢删** —— 源文件不敢动，重复文件越攒越多，硬盘越来越满。

传统办法？手动一个个拖、一个个改名、一个个比对……一天都未必够。

## 它能做什么：6 大核心能力

### 1️⃣ 一键探测，跨平台跨版本

不管你用的是 Windows、macOS 还是 Linux，微信 3.x 还是 4.x，它都能自动识别——连你电脑上登录过的多个微信账号，也会一并列出来让你选。

你不用记路径、不用看版本，开口说一句「帮我整理微信附件」就行。

### 2️⃣ .dat 解码还原：把乱码变回真文件

微信把图片、视频打包成 `.dat` 单字节加密容器。专家靠文件头特征反推密钥，自动还原成 `jpg / png / gif / bmp / pdf / zip / mp4` 等真实格式与扩展名。

再也不会出现「整理出一堆打不开的 .dat」。

【配图：decode.png】

### 3️⃣ 智能分类：按类型，也能按客户

- **按类型**：文档 / 表格 / 图片 / 视频 / 压缩包 / 音频 / 其他，再按「年-月」归档。最适合日常备份。
- **按客户**：用「文件名 + 文档正文」双路匹配，把文件自动归进对应客户文件夹。律师、IP 从业者按卷宗归档的利器。
- **自定义**：你写规则，它来执行。

【配图：classify.png】

### 4️⃣ sha256 内容去重：只看内容，不比名字

两个文件，名字天差地别但内容一模一样？它用 **sha256 哈希**比对，同内容只保留一份，其余标记出来告诉你「省了多少空间」。

**绝不靠文件名判断重复**——这是它最靠谱的地方。

【配图：dedup.png】

### 5️⃣ 安全增量：默认只预览，确认才动手

它默认进入「预览模式」，先把整理计划（每类多少、放哪、能省多少）列给你看，**必须你点头说「执行」，它才复制**。

复制不移动、不删除源文件；还会记录已处理哈希，下次只跑新增，秒级增量重跑。

### 6️⃣ 一键入库，全文检索

整理完，可把文件导入 WorkBuddy 资料库。文本类（`pdf / docx / xlsx / txt / md / csv`）支持**全文检索**——跨设备搜文件名、搜正文关键词，一秒定位。

## 它最硬的底牌：合规，且安全

很多人担心：整理微信文件，会不会动到我的聊天记录？会不会泄露隐私？

微信附件整理专家是**合规版**，从设计上就把边界划得清清楚楚：

- ✅ **只读本地文件**：只做文件系统读取与复制，**绝不读取、不解密、不导出聊天数据库**（MSGx.db），不解析任何聊天内容。
