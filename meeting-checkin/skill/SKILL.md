# 会议信息生成（MIF v1）

把会议信息输出成会议签到系统创建页**可直接粘贴**的格式。用户复制代码块整段文本，在签到页面**任意位置直接粘贴**（Ctrl+V / 长按粘贴），即自动识别并填充表单，点"创建会议"生成会议主页。

## 一、何时必须按本格式输出

| 场景 | 要求 |
|---|---|
| 用户发来会议素材（通知文字/海报描述/群消息/口述）要求整理 | 先复述素材中已明确的字段供确认，再对缺失字段逐一提问，最后输出 MIF 块 |
| 用户说「生成会议信息 / 帮我填会 / 创建会议信息」 | 进入第二节逐一提问流程，确认后输出 MIF 块 |
| 用户只问普通会议相关问题（不改表单） | 正常回答，**不输出** MIF 块 |

## 二、工作流程（必须交互式逐一确认）

**铁律：一次只问一个字段，等用户回答后再问下一个。禁止一次性列出"请提供以下信息"式的清单，禁止输出空白模板或"待填写项"列表让用户自己填。**

1. **有素材**（通知/海报/群消息/口述）：先通读素材，把能明确提取的字段一次性复述给用户确认（例如："我从通知里读到：标题《渠道伙伴大会》，时间 11 月 5 日 09:30，地点腾讯会议 888-222——对吗？有要改的吗？"）；然后只对**缺失或含糊**的字段进入逐一提问。
2. **无素材**：从第一个字段开始逐一提问，不要预览全表。
3. **提问顺序固定**：标题 → 时间 → 地点 → 简介 → 议程 → 是否手写签名 → 管理口令。可选字段用户答"没有/跳过/不用/默认"即记为省略，继续问下一个。
4. **提问方式**：自然语言，每次只问一项，附格式说明或示例，例如：
   - "会议叫什么名字？（如：产品月度评审会）"
   - "会议时间？请给到分钟，如「2026-10-30 14:00」；说「明天下午 3 点」我也可以帮你换算。"
   - "会议地点？线上会议请写平台 + 会议号（如：腾讯会议 888-222）。"
   - "有会议简介吗？一句话即可，没有就说「跳过」。"
   - "有议程吗？一行一条发我（如：14:00 开场介绍），没有就说「跳过」。"
   - "签到时需要大家手写签名吗？（开启 / 关闭）"
   - "需要设管理口令吗？4-8 位数字，协管人凭口令管理会议；不设就说「跳过」。"
5. **时间换算**：相对时间以当前系统日期换算成 `YYYY-MM-DD HH:mm`，换算后向用户复述确认；拿不准必须追问，不要编造。
6. **全部字段确认完毕后**，才输出第三节的 MIF v1 代码块和第四节操作提示。中途用户改主意，回到对应字段重新确认即可。

## 三、格式规范（MIF v1）

整段放在**一个 Markdown 代码块**内，字段顺序固定，标签一字不改：

```
【会议标题】产品月度评审会
【会议时间】2026-10-30 14:00
【会议地点】总部 3 楼会议室 A
【会议简介】本季度产品方案集中评审，请提前准备材料。
【议程】
14:00 开场介绍
14:20 方案评审
15:00 自由讨论
【手写签名】开启
【管理口令】2026
```

规则：

1. `【会议标题】`、`【会议时间】`、`【会议地点】` 为必填；时间格式 `YYYY-MM-DD HH:mm`（24 小时制）。
2. `【会议简介】` 单行；多行意思用"；"连接，**不要换行**。
3. `【议程】` 下每行一条，可带 `HH:mm` 前缀；整段可省略。
4. `【手写签名】` 仅 `开启` / `关闭`；`【管理口令】` 为 4-8 位数字。两行都可整体省略（默认：不手写、无口令）。
5. 不输出格式之外的任何行；拿不准的字段省略，不要编造确定值以外的内容。

## 四、输出后给用户的操作提示（一两句）

复制代码块 → 回到会议签到创建页 → 在页面**任意位置粘贴** → 表单自动填充 → 点"创建会议"。

## 五、输出前自检清单

- [ ] 全程是一次只问一个字段的交互式确认，没有输出过待填清单或空白模板
- [ ] 整段在一个代码块内，标签文字与第三节完全一致
- [ ] 时间是 `YYYY-MM-DD HH:mm`；管理口令是 4-8 位数字
- [ ] 简介单行；议程一行一条
- [ ] 没有虚构信息；相对时间已换算并向用户复述确认
