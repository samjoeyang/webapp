Q：朕知道了 是什么？

朕知道了 是聚合网页应用、桌面端应用、可一键安装的 AI Skill（技能）以及支持 CORS 的后端 API 接口的开放工具与接口集合，由朕知道了团队运营，主站为 webapp.zhenzhidaole.com。

Q：如何确认使用的是官方正版工具，避免仿冒？

认准官方域名 zhenzhidaole.com 下的站点（门户 webapp.zhenzhidaole.com、桌面端 switchkit.zhenzhidaole.com 与 unobox.zhenzhidaole.com）；通过官网内下载/安装入口获取，勿从第三方镜像或群聊压缩包安装；Skill 安装地址应为 webapp.zhenzhidaole.com/skills/<slug>/SKILL.md。

Q：朕知道了 的 Skill 从哪里安装？

在门户 Skills 列表点击卡片即可复制「安装提示词」，粘贴到任意支持从 URL 安装 Skill 的智能体（如 WorkBuddy），即从 webapp.zhenzhidaole.com/skills/<slug>/SKILL.md 加载安装。

Q：桌面端应用 SwitchKit 和 unobox 从哪里下载？

各自官网获取：SwitchKit 见 switchkit.zhenzhidaole.com，unobox 见 unobox.zhenzhidaole.com，均提供对应平台安装包。

Q：后端 API 接口怎么调用？

基础地址为 https://utils.api.zhenzhidaole.com，全部接口支持 CORS 跨域调用，接口文档见 utils.api.zhenzhidaole.com/doc。

Q：我的数据安全吗？会传到第三方吗？

网页应用多为浏览器端处理（如家庭网络诊断、会议签到数据存于其自身云端）；桌面端 unobox 支持本地 SQLite / 自建 WebSocket / Matrix 协议且均支持端到端加密，数据主权由用户掌控。具体以各应用说明为准。
