# 文档审校

在文档发布/发送前做一次快速把关，重点是**挑错**而非润色。检查四类问题，输出最关键的最多 5 项。

## 一、说明

| 检查项 | 含义 | 典型表现 |
|---|---|---|
| 错别字 | 字形/拼音/简繁混用导致的错字、漏字、多字、用词不当 | 「计画」应为「计划」；「按排」应为「安排」；「的/地/得」误用 |
| 时间矛盾 | 文中时间逻辑冲突或相对时间与绝对时间对不上 | 初稿完成日期晚于提交日期；「上周」换算后落在未来 |
| 数字口径 | 数字单位/口径/精度不一致，或上下文数值对不上 | 「约 5 万元」与「实际 50000 元」重复又口径不一；占比与绝对值矛盾 |
| 缺失条件 | 关键前置信息、责任主体、时间节点、依据缺失 | 有预算无审批说明；有截止日无责任方；引用条款无出处 |

## 二、触发条件

- 用户说「审校 / 校对 / 检查文档 / 帮我看看有没有错 / 把关一下 / 发布前挑挑错」并附文本。
- 用户粘贴文章、报告、邮件、合同、通知等，要求检查质量或挑错。
- 用户完成初稿后要求「先挑错再润色」。
- 不触发：用户只要求翻译、改写、总结或纯格式调整且未提「检查/挑错」时，正常处理，**不**强制走本流程。

## 三、步骤

1. **通读定位**：通读全文，按段落/句子编号，建立可引用的定位锚点（如「第 2 段第 1 句」或行号）。
2. **逐类扫描**：按上表四项依次检查：先扫错别字，再查时间线，再对数字口径，最后看缺失条件。注意同一处可能命中多项。
3. **评级排序**：给每条问题标严重程度（高/中/低）。高=事实性错误、会引发歧义或责任风险；中=明显笔误但意思可猜；低=可优化项。
4. **收敛输出**：**只列出最严重的至多 5 项**；若发现超过 5 项，取前 5，并补一句「另有 N 项次要问题略」。不堆砌清单，不列无把握的猜测。
5. **按格式输出**：每条用「定位 → 问题 → 建议」三段式。

### 输出格式

```
【文档审校结果】（共发现 X 项，列出最关键 5 项）

1. 〔高〕第 2 段第 1 句 — 时间矛盾
   问题：初稿完成日(1/5)晚于提交截止日(12/20)，逻辑倒置。
   建议：核对实际日期，将提交截止日改为初稿之后，或修正初稿完成日。

2. 〔中〕第 1 段 — 错别字
   问题：「计画」为繁体误用，正文应统一用简体「计划」。
   建议：改为「计划」。

…（最多 5 条）

另有 N 项次要问题略。
```

## 四、演示文字（内置 2 句）

技能内置以下 2 句演示文本，可用来验证四类检查逻辑是否生效：

> **演示句 1（错别字 + 时间矛盾）**：项目于 2024 年 1 月 5 日完成初稿，并计画于 2023 年 12 月 20 日前提交评审。

> **演示句 2（数字口径 + 缺失条件）**：本次采购预算约 5 万元，实际支出 50000 元，需在领导批准后执行，具体由谁负责未说明。

预期命中：句 1「计画」错别字、初稿日与提交日时间矛盾；句 2「约 5 万元/50000 元」口径重复、缺责任主体（缺失条件）。

## 五、自检清单

- [ ] 已通读全文并建立定位锚点，未凭片段下结论
- [ ] 四类问题（错字/时间/数字/缺失）均已扫到，未漏类
- [ ] 输出问题数 ≤ 5，超出已用「另有 N 项略」收敛
- [ ] 每条含「定位 → 问题 → 建议」三段，无空泛批评
- [ ] 未臆造事实；拿不准的标为「待确认」而非断言
