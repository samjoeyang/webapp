# 精读一书智能体

## 概览

本技能把一本书加工成结构稳定的几分钟精读内容，支持两条素材路线（公开解读 / 全书解析），按“分块摘要 → 主线合并 → 压缩成稿 → 事实校验”分层蒸馏，并在定稿后按需接力配音、字幕、配图与视频成片。

## WorkBuddy 环境适配（2026-11-23）

- 配图用内置 `ImageGen`；视频片段用内置 `VideoGen`（支持文生视频与首帧图生视频）。两者调用前必须告知用户额外积分消耗。
- 当前 WorkBuddy 未提供内置 TTS。若环境无可用文字转语音工具，L2/L3 配音降级为：交付口播稿、SRT 时间轴与静音占位，由用户提供音频后再对齐；不得声称已生成配音。
- 原文中 `text_to_audio_plus`、`audio_to_audio_plus`、`doubao-creative-video`、`byted-mediakit-video` 等工具名来自其他平台，仅在工具真实存在时调用；调用前先发现真实 schema，不臆造参数，不存在时按上述映射降级。

## 通读覆盖与降级规则（2026-11-23 补）

- 路线 B 默认必须逐块读完：用 `split_chapters.py` 切块，逐块按 `prompts.md` 出摘要，再合并。不得以「目录/小节标题 + 开头摘录」替代逐块摘要。
- 因上下文或时间确实无法逐块读完时，按以下兜底执行：
  1. 在 `brief.md` 的「存疑待核 / 元信息」写明实际覆盖率（已读块数/总块数，或抽样字符占比）与抽样方式；
  2. 结论降级为「框架级/中等置信」：只保留在多个独立小节反复出现的主线；仅由单个标题或单段支撑的因果、权重、数字不得写成定论；
  3. 关键数字/金句必须回查到原文具体文件与位置，列入「来源与章节留痕」；未回查一律标「存疑待核」；
  4. 发现缺卷/重复卷先向用户确认，不得按套装标题补全内容；
  5. 事实校验增加一问：结论是否超出实际读取覆盖范围。超出项删除或降格为「存疑待核」。

## 开工前判断

1. **素材路线**（见 `references/pipeline-design.md` 第 1 节）
   - 只给书名/作者 → 路线 A：联网搜索，交叉 2 个以上来源；
   - 上传 PDF/EPUB/TXT/扫描件 → 路线 B：解析原文，超长文本切块分批处理。
2. **产物级别**（见 `references/video-pipeline.md` 第 1 节）
   - 默认只交付 L1 文字精读稿；用户明确要音频/视频时再逐级向下，不跳过确认直接生成。
3. **可变参数**：目标时长（默认 3~5 分钟）、语速（默认 240 字/分钟）、口吻、受众、重点数量；缺失时用默认值并在成稿前告知用户。

## 主工作流

### 步骤 1：获取素材
- 路线 A：未提供电子书文件时，按 `references/source-collection.md` 的平台优先级（按可读正文量排序，微信读书/国图/QQ阅读/掌阅/得到/豆瓣阅读在前，试读与元数据平台在后，聚合站仅作线索）依次检索；搜索不足时用浏览器读取可见页面，记录来源并多来源交叉。
- 路线 B：读取上传文件；扫描图片先 OCR；长文本先跑切块脚本（见下方脚本清单）。

### 步骤 2：分块摘要
按 `references/prompts.md`「分章摘要」模板，逐章/逐块提炼核心论点、案例数据、金句与章节作用；只依据素材，不发挥。

### 步骤 3：主线合并
按「主线合并」模板梳理：核心问题、论证结构、最终结论、关键概念；标出可舍弃的次要分支。

### 步骤 4：压缩成稿
- 套用 `assets/brief_template.md`，按「压缩成稿」模板写成口播稿；
- 篇幅匹配目标时长；成稿末尾附配图/画面建议；
- 跑 `scripts/estimate_duration.py` 校验时长：偏短补案例，偏长砍次要分支。

### 步骤 5：事实校验
按「事实校验」模板对照素材逐条核对：观点是否有依据、有无编造案例/金句、是否把引申当成原意；未命中内容删除或标「存疑待核」。

### 步骤 6：交付定稿
- L1：交付 `brief.md` 与口播纯文本；
- 需要后期时，按 `references/video-pipeline.md` 继续阶段 1~5。

## 后期链路（按需启用）

- **配音风格预审（强制前置）**：按 `references/voice-presets.md` 依题材选定一套锁定音色 profile（性别/年龄感/音色/语速/情绪），方案确认一次后全片复用，中途不换声线。
- **自动配音**：用 `text_to_audio_plus`（有参考音色用 `audio_to_audio_plus`）按分句分段合成，前缀复用同一 profile；再用 `scripts/concat_audio.py` 拼接成一条完整 WAV；调用前先 `tool_search` 获取真实 schema。
- **字幕**：`scripts/script_to_srt.py` 生成 SRT 与分句 JSON；配音完成后以实际音频时长复核对齐。
- **分镜与配图**：先出分镜表对齐口播节奏，再用 `image_gen` 按分镜生成配图，风格与画幅前后统一。
- **视频生成与合成**：动态片段生成前必须先加载 `doubao-creative-video` Skill 完成参数确认，再调用 `text_to_video` / `image_to_video` / `media_to_video`；图文成片（静态配图+配音+字幕）确认画幅后可自动合成；拼接、字幕压制、转码走 `byted-mediakit-video`。

详细工具映射、自动化边界、确认点与降级方案见 `references/video-pipeline.md`。

## 脚本清单

| 脚本 | 用途 |
|---|---|
| `scripts/split_chapters.py` | 长文本按章节/字数切块，输出 chunks.json |
| `scripts/estimate_duration.py` | 按字数估算口播时长，判断是否在目标区间 |
| `scripts/script_to_srt.py` | 口播稿分句，输出 SRT 字幕与 lines.json |
| `scripts/concat_audio.py` | 分段配音下载并无损拼接为一条完整 WAV，输出总时长 |

## 风险底线

对外发布前核对 `references/risks.md`：不大段复述版权原文、不编造书中细节、标注速读解读不替代通读；专业书籍附加“不构成专业建议”提示。
