# 风险与合规注意事项

## 1. 版权与素材来源
- **前置风险提醒**：进入流程前若判定版权/授权状态存疑，先向用户明确提示风险（来源是否正版、可否对外发布、不得大段复述等）；提醒后用户明确坚持生成的，可继续，但责任由用户承担，且本技能仍须守住下方采集边界。
- 上传全书解析仅限个人学习/内部使用；对外发布精读稿、配音、视频时，不得大段复述原书受版权保护的表达，只提炼观点、结构与有限引用。
- 路线 A 的搜索素材要记录来源；转述他人读书笔记时区分原书观点与解读者引申。
- 配图、背景音乐、影视片段使用有授权或可商用的素材；不要在成片中混入未授权的书封原图、影视截图。
- 聚合搜书站与第三方 PDF 镜像多为非授权分发，只用于确认版本/目录线索，不作为定稿事实来源，不整段复制其正文；商用发布前替换为正版平台来源。

## 2. 幻觉与事实偏差
- 模型可能编造书中不存在的案例、数据、人名、金句；定稿前必须过事实校验节点（见 `pipeline-design.md` 第 5 节）。
- 拿不准的内容标「存疑待核」，不要为了成稿通顺放行。
- 路线 A 为二次转述，结论与原书可能有出入；重要引用建议对照原书章节复核。

## 3. “快”不等于“读完”
- 几分钟精读是框架级提炼，会舍弃细节、案例背景与论证过程；成稿中应说明这是速读解读，不替代通读原书。
- 不要用“读完/吃透全书”等绝对化表述宣传产出内容。

## 4. 时长与篇幅风险
- 口播时长按字数估算，实际配音语速会有偏差；正式配音后以音频实际时长为准复核。
- 偏长稿件先砍次要分支，不要靠压缩语速硬塞时长。

## 5. 平台与发布合规
- 对外发布前核对目标平台对图书解读、引流、素材授权的规则；
- 涉及医疗、法律、金融等专业书籍时，标注“内容为书籍观点梳理，不构成专业建议”。
