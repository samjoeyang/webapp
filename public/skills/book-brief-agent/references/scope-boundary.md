# 内容范围与精读边界规则

> 本文件规定一次精读任务到底覆盖「全书」还是「指定章节」，以及范围如何确认、变更如何回退。所有采集、摘要、成稿、配音、分镜、画面环节都以确认后的范围字段作为边界依据，不得越界。

## 目录
1. 内容来源范围
2. 边界确认清单
3. 范围变更回退规则
4. 字数与时长适配
5. 元卡片范围字段
6. 系列视频补充规则

## 1. 内容来源范围

| 范围类型 | 适用场景 | 采集口径 |
|---|---|---|
| 全书（默认） | 无特殊说明时，默认对整本书做精读总结 | 遍历全部章节/切块，不跳章、不只挑热门章节 |
| 指定单章 | 聚焦某一章独立核心论点 | 只在该章正文内采集、提炼，不引入其他章节 |
| 指定多章 | 围绕统一主线跨指定章节重组内容 | 只在用户点名的章节范围内采集，不擅自扩充到未选定章节 |

**默认规则（固定）：**
- 用户没有特别说明章节范围时，一律按**全书**处理；
- 只有用户**明确指定**单章或哪几章时，才切换为局部范围；
- 局部范围下，未被选定章节的观点、案例、金句不得进入成稿与画面。

## 2. 边界确认清单

启动流程前，元卡片必须逐项明确：

1. **书名 + 版本信息**（作者、译者、版本/出版信息）；
2. **选定范围**：全书 / 指定单章 / 指定多章；局部范围须写明具体章节编号与标题；
3. **本视频/文稿统一主线**：一句话说明本次要讲清楚的核心问题或主张；
4. **目标受众**（沿用受众标签：学生/青年/成年人、少儿向等，缺省为普通成年人）；
5. **判定口径**：所有采集与提炼严格限定在已确认范围内，绝不主动拉入未选定部分的信息。

清单缺项时只补问缺失项，不脑补书名、版本、章节或主线。

## 3. 范围变更回退规则

1. **中途改变范围**：由全书改为指定章节，或由单章扩充为多章/全书，视为内容边界变更，直接回退到素材采集与文稿重写环节重新采集、重新摘要；原有后续产出（摘要、总稿、配音、字幕、分镜、配图、成片）**自动作废**，不得在旧稿上打补丁。
2. **同范围内部微调**：不增减章节边界，只是精简表述、调整措辞或替换局部案例，则沿用原有流程内的校验规则处理，不需要从头全量重启。
3. **中途换书/换章节**：回到边界确认清单重新确认书名、范围与主线，后续节点按新内容执行。

## 4. 字数与时长适配

1. 无论选定范围是全书还是局部章节，目标区间仍为 **8～9 分钟口播**，硬性上限 **2500 字**（语速基准 220 字/分钟，详见 `prompts.md` 第 3 节）。
2. **内容体量过小**：只允许在已选定素材内补充有效信息（案例、论证细节），禁止跨范围引入其他章节或外部脑补内容来凑时长。
3. **内容体量过大**：按既定优先级 P0（主线/核心论点/金句/核心争议/来源标记）→ P1（次要修饰/重复表述/过渡铺垫）→ P2（旁支细节/非核心案例）取舍，保证边界不越线。
4. 时长、字数测算规则沿用 `scripts/estimate_duration.py` 与 `prompts.md` 篇幅基准；局部范围成稿同样需跑时长校验。

## 5. 元卡片范围字段

1. 元卡片内固定新增 **【内容范围】** 字段：
   - 全书：标注 `【范围：全书】`；
   - 局部：标注 `【范围：第 X 章 章节标题】` 或 `【范围：第 X、Y、Z 章 章节标题】`。
2. 后续所有节点（素材采集、摘要、成稿、配音、分镜、画面生成）都以该字段作为边界校验依据。
3. 范围发生变动时，元卡片同步刷新，旧版本字段与对应产出一并标记作废。

## 6. 系列视频补充规则

1. 同一本书拆分为多支独立视频时，**每一集单独确认范围与主线**，各自填写元卡片【内容范围】与主线一句话。
2. 全套剧集统一配音音色、美术风格、视觉体系、开场结尾结构，保持连贯；单集内部仍遵守本规则。
3. 单集依旧遵守 8～9 分钟目标区间、2500 字硬上限；不因系列化而放松篇幅约束。
4. 每一集元卡片标注清楚：系列第几集、对应章节范围、在整套中的位置；集与集之间引用前情时，只做简要回顾，不重复展开已讲内容。
