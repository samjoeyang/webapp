# 分镜、画面提示词、生成合成与终审规则

## 1. 触发时机与前置条件

- 进入本链路前，必须满足：文稿定稿、事实校验通过、配音与时间轴字幕全部校验通过，且用户确认推进视频。
- 以**已确认的音频时间轴**为分镜锚点；不以画面反推音频。
- 文稿或配音发生改动（增删段落、换重点、重新配音），本链路此前产出的分镜、提示词、配图、片段自动作废，回到对应环节重跑。

## 2. 分镜拆分原则

1. **时间锚点**：按音频/字幕时间轴切分镜头，起止时间对齐音频。
2. **镜头时长**：标准单镜头 **3～6 秒**；硬性上限 **8 秒**，不得突破。
3. **一镜一信息**：每个镜头只承载一个核心信息，不把整段论证塞进一张画面。
4. **视觉连贯**：相邻镜头在同一视觉世界内推进，不无故跳变场景。
5. **画面文字**：画面内文字清晰自然，只突出关键词，不把旁白全文贴满屏幕。

## 3. 画面风格基准

1. **风格绑定题材与受众**：全套镜头保持同一种美术基调，在开工前由首镜锁定。
   - 面向学生/青年/成年人：质感沉稳克制、写实为主，干净高级；拒绝花哨卡通、夸张特效。
   - 少儿向：柔和温润，画面简洁，色彩舒适，不过度喧闹。
   - 全程统一光影方向、明暗层次与配色体系，贯穿整支视频。
2. **金句镜头**：金句对应镜头重点突出文字，视觉上加重氛围感，但整体风格不变，不单独换画风。
3. **禁止项**：脱离旁白凭空增加无关画面；强行加入猎奇元素；前后画风割裂。

## 4. 提示词固定结构

每个镜头的正向提示词按以下顺序拼装，字段不缺：

1. **主体**：本镜头对应的核心视觉元素（匹配当前旁白内容）；
2. **场景**：环境、空间；
3. **美术风格**：沿用第 3 节锁定的统一风格预设；
4. **构图/镜头**：平视、慢推、固定机位、景别等；
5. **画质约束**：高清，细节自然，无畸形物体，画面干净。

另为每个镜头准备一条**备选兜底提示词**，用于首版生成跑偏时替换重试。

## 5. 镜头信息配比

1. **信息密度**：单镜头信息精简，核心信息不叠加、不挤压。
2. **画面文字**：只放关键词，不贴旁白全文。
3. **画面变化**：镜头之间有适度变化，但变化幅度不破坏整体统一感。
4. **情绪递进**：随旁白情绪推进，画面光影、节奏、景别可轻微递进，但始终保持同一视觉世界。

## 6. 分镜表字段与自检

### 6.1 分镜表固定字段（按时间顺序排列）

| 字段 | 说明 |
|---|---|
| 镜头编号 | 顺序编号 |
| 起止时间 | 对齐音频时间轴 |
| 对应旁白片段 | 该镜头覆盖的旁白原句 |
| 画面核心主体 | 本镜头核心视觉元素 |
| 完整正向提示词 | 按第 4 节结构拼装 |
| 备选兜底提示词 | 首版失败/跑偏时替换用 |
| 备注 | 金句标记 / 特殊效果标记等 |

### 6.2 自检项目

- 画面与旁白内容强绑定，无脱离原文的无关画面；
- 全片风格、光影、色调保持一致；
- 时长落在 3～6 秒区间，不突破 8 秒硬上限；
- 金句位置标注无误；
- 无畸形元素、无过度花哨特效。

## 7. 画面生成执行顺序

1. **先锚定首镜**：以第 1 镜头作为全片风格基准，锁定主体、色调、光影、构图和画质。
2. **再批量续镜**：后续镜头必须继承首镜风格，不允许逐镜自由发挥。
3. **一致性校验**：每生成一批画面，先比对首镜，确认风格统一后再进入合成。
4. **异常处理**：某镜头风格跑偏或画面崩坏，只重生成该镜头，不影响已通过镜头。

## 8. 素材一致性规范

1. **统一视觉世界**：全片保持同一时代感、同一空间逻辑、同一色彩体系。
2. **主体连续**：人物、物品、场景、服装等前后镜头保持一致，不发生无故换装、变形或跳变。
3. **光线连续**：相邻镜头光源方向、明暗、色温保持合理衔接。
4. **构图节奏**：镜头变化服务信息推进，不做炫技式乱切。
5. **文字一致**：画面内若出现文字，字体层级、颜色、位置风格统一。

## 9. 音画合成基本规则

1. **音频为主时间轴**：视频画面严格贴合已确认的音频时间轴，不以画面反推音频。
2. **口型/动作同步**：有人物口播时，口型、停顿、呼吸与声音同步。
3. **旁白画面同步**：旁白说到关键主体时，画面主体同步出现或强化。
4. **镜头转场**：优先克制转场（硬切、淡入淡出、推拉衔接），不使用过度炫技转场。
5. **留白处理**：情绪重的位置允许画面短暂停留，用节奏强化记忆点。

## 10. 全片节奏与情绪控制

1. **开场 0～3 秒**：快速建立主题、人物或冲突，避免铺垫过长。
2. **中段推进**：信息密度稳定，镜头节奏跟随旁白情绪轻微递进。
3. **高潮/金句段**：画面重点聚焦，减少无关信息，必要时放慢节奏。
4. **结尾收束**：落点清晰，避免突然结束；可用稳定定格、黑场或音乐渐弱收尾。
5. **音乐音效原则**：音乐服务情绪，不压人声；音效只强化关键动作。

## 11. 终审标准与交付

1. **内容终审**：画面与旁白强绑定，无偏离原文的无关内容。
2. **技术终审**：无明显畸形、穿帮、跳帧、闪烁、文字错误、音画错位。
3. **风格终审**：全片视觉世界统一，节奏连贯，不出现前后割裂。
4. **成片输出**：按确认比例输出完整视频，并附最终版本说明。
5. **版本留痕**：交付时说明素材路线、内容范围、画幅、音色 profile 与本次修改点。

## 12. 异常兜底与修改原则

1. **生成失败兜底**：某镜头提示词反复生成失败，标记该镜头并保留空白占位，提示用户确认替换方案；不强行输出崩坏画面。
2. **小改**：仅调整局部镜头或音画节奏，在当前节点内局部重做。
3. **大改**：改动文稿、配音、范围或整体风格时，回到对应节点重做，不越级乱改；作废产出按第 1 节规则处理。
