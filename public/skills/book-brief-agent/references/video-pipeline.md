# 配音与视频后期链路（自动化版）

> 本文件说明精读稿定稿之后，接力产出配音、字幕、配图、分镜与成片的完整链路：哪些环节自动执行、哪些节点必须人工确认、用什么工具与脚本。链路按分级产物推进，任一级别都可作为最终交付。

> WorkBuddy 映射（2026-11-23）：配图走内置 `ImageGen`，视频片段走内置 `VideoGen`（调用前须告知积分消耗）；当前环境无内置 TTS，无外部 TTS 时 L2/L3 配音降级为 SRT + 静音占位 + 用户音频后对齐。下文 `text_to_audio_plus`、`audio_to_audio_plus`、`doubao-creative-video`、`byted-mediakit-video` 属原平台工具名，仅在真实可用时调用，否则按本段降级执行。

## 1. 产物分级与自动化程度

| 级别 | 交付物 | 自动化程度 |
|---|---|---|
| L1 | 精读稿 Markdown / 口播稿文本 | 全自动 |
| L2 | 口播稿 + 完整配音 WAV | 风格方案确认一次后，自动分段合成并拼接成一条 |
| L3 | L2 + SRT 字幕 + 分句清单 | 自动生成；配音完成后按实际时长复核对齐 |
| L4a | 图文成片：静态配图 + 配音 + 字幕 | 确认画幅后自动合成 |
| L4b | 动态视频成片：视频片段 + 配音 + 字幕 | 片段生成前必须确认参数；后期拼接压制自动 |

用户未明确要音频/视频时，默认先交付 L1；用户说“配音/做成视频”时按对应级别向下推进。

## 2. 阶段 0：成稿定型

- 定稿后先跑 `../scripts/estimate_duration.py` 校验时长；偏长先压缩，偏短再补充。
- 确认输出形态：纯文字 / 图文笔记 / 竖屏短视频（默认 9:16）/ 横屏（16:9）。
- 记录目标时长、语速、口吻、受众（见 `prompts.md` 可变参数），配音与画面沿用同一套参数。

## 3. 阶段 1：配音风格预审

> 这是新增的强制前置节点，避免音色、语气与书籍基调不搭。

1. 读定稿成稿，判断题材与基调，按 `voice-presets.md` 选定一条预设，得到锁定的 `VOICE_PROFILE`（性别/年龄感/音色质感）、语速 wpm、情绪说明。
2. 形成配音方案：音色、语速、情绪、是否配背景音乐；用户有明确偏好时覆盖对应字段，其余沿用预设。
3. 方案告知用户并确认一次；用户无特别要求时按预设直接执行。**全片复用同一 profile，中途不得换声线。**

## 4. 阶段 2：自动配音与拼接

### 工具
- `text_to_audio_plus`：文生 WAV 人声；用户提供参考音色时改用 `audio_to_audio_plus`。
- 调用前先 `tool_search` 发现工具 schema，按实际参数传入，不臆造字段。

### 执行步骤
1. 按 `script_to_srt.py` 输出的分句清单，把文本切成 ≤100 秒的段（留 120 秒上限余量）；切点落在句子边界。
2. 每段 prompt 按 `voice-presets.md` 第 4 节格式拼装，前缀为同一 `VOICE_PROFILE`，正文放末尾。
3. 逐段生成 WAV，收集返回 URL；写入分段清单 JSON（每项 `index` + `url` 或 `local_path`）。
4. 跑 `../scripts/concat_audio.py` 统一格式并无损拼接：
   `python3 concat_audio.py manifest.json --out audio/merged.wav --sample-rate 40000`
5. 抽查各段声线、语速一致性；某段明显不同，用同一 profile 重生成该段后重新拼接。
6. 按媒体交付规则用 `present_files` 交付完整 WAV，文件名以 `.wav` 结尾。

### 约束
- 单次生成 ≤120 秒；不使用未授权真人声纹克隆。
- 背景音乐不在人声 TTS 内生成；需要时后期单独添加并压低衬底。

## 5. 阶段 3：字幕

- 跑 `../scripts/script_to_srt.py` 生成 SRT 与分句 JSON：
  `python3 script_to_srt.py script.txt --wpm <语速> --gap 0.3 --out-dir subtitle`
- 配音完成后，以实际音频时长为准复核时间轴；偏差较大时按实际时长重排，不硬套估算轴。

## 6. 阶段 4：分镜与配图

### 分镜脚本
- 按分句清单 + 成稿末尾“配图/画面建议”生成分镜表，每条含：序号、对应句子/时间段、画面描述、画幅、素材类型（静态图/视频片段）。
- 分镜表是配图与片段生成的依据，保证画面与口播节奏对齐。

### 配图
- 用 `image_gen` 按分镜逐张生成；全片风格统一（色调、写实/插画、画幅）。
- 封面单独生成，预留标题位；画幅跟随成片比例（竖屏 9:16 / 横屏 16:9）。

## 7. 阶段 5：视频生成与后期合成

### 工具路由（调用视频生成工具前必须加载 `doubao-creative-video` Skill）
| 需求 | 工具 |
|---|---|
| 纯文字描述生成片段 | `text_to_video` |
| 以配图为首帧/参考图生成片段 | `image_to_video` |
| 已有视频片段 + 图片/配音合并创作 | `media_to_video`（必须至少含一个视频输入） |
| 片段拼接、字幕压制、转码、音画对齐、抽帧等后期 | `byted-mediakit-video`（mediakit-cli）；纯音频拼接用 `concat_audio.py` |

### 强制确认点（不可绕过）
- 调用任一视频生成工具前，必须按 `doubao-creative-video` Skill 要求完成参数确认：模型、时长、比例、条数、内容与分段安排，经用户明确同意后再生成；未确认不得调用。
- 静态配图 + 配音 + 字幕的图文成片，在画幅确认后可自动合成，不触发上述片段生成确认。

### 执行要点
- 单段生成时长受模型限制（常见 4~15 秒，部分模型 4~30 秒）；长片拆成多段分别生成，再后期拼接。
- 配音作为完整音轨对齐画面；字幕用阶段 3 的 SRT 后期压制，不在生成工具里烧录。
- 每个成功生成的片段/成片按媒体交付规则逐项交付，不自行筛片、不扣留结果。

### 合成顺序
```
配音分段 WAV → concat_audio.py 拼接完整音轨
分镜表       → 配图 / 视频片段按时间轴排列
SRT 字幕     → 后期压制
转码/封装    → 输出最终成片
```

## 8. 自动化边界总表

| 环节 | 是否自动 | 说明 |
|---|---|---|
| 素材检索、成稿、校验、时长估算 | 自动 | Skill 主流程 |
| 字幕分句与 SRT | 自动 | 脚本生成 |
| 配音风格方案 | 预审后确认一次 | 题材匹配预设，用户可覆盖 |
| 分段配音 + 拼接完整音轨 | 自动 | 同一 profile，脚本拼接 |
| 分镜表、配图初稿 | 自动 | 风格与画幅需与成片一致 |
| 动态视频片段生成 | 确认后执行 | 工具参数必须经用户同意 |
| 后期拼接、字幕压制、转码 | 自动 | mediakit-cli / ffmpeg |
| 成片发布、对外口径 | 人工 | 不自动发布 |

受限/不可自动：单次配音 >120 秒；单段视频超模型时长上限；未授权真人音色克隆；自动抓取受版权保护全书全文分发（见 `risks.md`）。

## 9. 目录与文件约定

```
<任务目录>/
├── brief.md              # L1 定稿精读稿
├── script.txt            # 口播纯文本
├── chunks.json           # 切块清单（路线 B）
├── audio/
│   ├── manifest.json     # 分段配音清单（url/local_path）
│   ├── parts/            # 分段下载与暂存
│   └── merged.wav        # L2 完整音轨
├── subtitle/             # L3 SRT 与 lines.json
├── visuals/              # L4 配图、分镜表、视频片段
└── final/                # L4 成片
```

## 10. 常见失败与降级

| 情况 | 处理 |
|---|---|
| 配音工具返回错误 | 按错误提示修正 prompt；仅在错误明确建议时重试；仍失败则交付文本稿，说明配音未生成 |
| 分段音色不一致 | 用同一 VOICE_PROFILE 重生成问题段，重新拼接 |
| 视频参数与模型限制冲突 | 按模型枚举调整比例/时长；不支持的选项先请用户重选，不静默替换 |
| 音画时长对不齐 | 以实际音频时长为准重排时间轴与片段切点 |
| 用户只要文稿 | 停在 L1，不主动生成音频/视频 |
