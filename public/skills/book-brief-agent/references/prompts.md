# 可复用提示词模板

> 占位符用 `{{变量}}` 标注；实际使用前替换。所有模板默认中文输出。变量不在模板内臆造，素材缺失时先向用户索取或标注存疑。

## 目录
1. 分章摘要
2. 主线合并
3. 压缩成稿（口播）
4. 事实校验
5. 可变参数

## 1. 分章摘要

每个切块固定输出以下四段，字段不增不减：

```
### 切块 {{index}}｜{{title}}
**核心论点**：1~3 条，每条一句话，只陈述作者主张，不评价对错。
**关键案例/数据/人物**：保留可回溯的细节（人名、数字、事件），注明在素材中的位置；只列素材里出现过的。
**金句**：原文照抄，不改写、不缩写；无则写「无」。
**章节作用**：铺垫 / 论证 / 转折 / 收尾 之一，一句话说明该块在全书中的功能。
```

提示词模板：

```
你是一名读书拆解编辑。下面是书籍《{{书名}}》的{{章节定位，如：第一章/切块 N}}原文（或公开资料摘录）：

【素材】
{{chunk_text}}

请只基于以上素材提炼，按固定四段输出：核心论点（1~3 条，每条一句话）、关键案例/数据/人物（保留可回溯细节并注明素材位置）、金句（原文照抄，无则写「无」）、章节作用（铺垫/论证/转折/收尾）。

约束：
- 素材中没有的内容一律不写；不做主观发挥；
- 不评价作者对错，只复述观点；
- 论点用编辑转述，金句用原话并加引号；
- 单块摘要总篇幅控制在切块正文的 15%~25%，不写得比原文长；
- 找不到依据的字段写「无」，不补；
- 输出为结构化 Markdown，不要寒暄。
```

### 同章多块合并规则

一章被切成 2 个以上小块时，分两步：
1. 先逐块按固定四段出摘要，保留块编号；
2. 再合并为一条章节摘要：核心论点去重合并；案例/数据/人物汇总不丢细节；金句汇总并标注来自哪个块；章节作用取该章整体功能；合并后仍用固定四段，块编号映射留存备查。

合并校验：核对该章块数；合并后的案例/金句不得无中生有；块摘要与章节摘要两层都留存，主线合并节点只吃章节摘要。

### 金句标准
- 必须是作者原话、完整句子，有概括力或表达张力；普通叙述、过渡句、罗列数据不算金句；
- 一条金句对应一个完整句子，不拼接两句、不掐头去尾；翻译书照录中译文，不回译；
- 每块金句上限 3 条，一章合并后仍 ≤3 条，超出只留最能代表主张的；
- 金句加引号原文照抄并标注出处（章节/块编号）；无合格金句写「无」，不硬凑、不改写包装。

### 案例/数据/人物标注
- 只收录素材中明确出现的信息，不脑补背景；数字、时间、人名严格原样保留，不四舍五入、不润色；
- 每条末尾附来源标记：路线 B 用【来源：章节名｜块编号】；路线 A 用【来源：平台｜链接片段｜情绪标签】；
- 单条案例控制在三句话以内，保留核心因果，剔除无关修饰；无有效内容填「无」。

### 路线 A 的块定义
- 不以原书章节为切块基准，按独立来源单元切块：单条试读片段/单篇官方解读/单篇长书评各为一个独立块；短评可批量归并为一个汇总块并统一打情绪标签；
- 每个来源块沿用相同四段式摘要模板；多个来源指向同一内容时交叉核验，矛盾点单独标记【存疑】，不强行统一；
- 来源单元不足时如实标注缺口，不虚构章节结构。

### 禁止发挥边界
1. 不补充素材内没有的背景知识（用户明确要求追加除外）；
2. 不替作者下对错评判；只客观收录来源自带的正/中/负评价并保留情绪标签；
3. 不提前跨章串联推导新结论，串联统一放到总稿环节；
4. 不扩写、美化原文，转述保持中性；金句严格原样引用；
5. 不删减关键限定条件（前提、适用范围、让步说明），防止断章取义；
6. 逻辑明显断裂处标记【逻辑断点】，不主动补全。

## 2. 主线合并

```
你是一名主编。以下是《{{书名}}》各章摘要：

【各章摘要】
{{chapter_summaries}}

请合并梳理出全书主线，输出：
- 作者要解决的核心问题（1 句）
- 全书论证结构：分几步推进，每步对应哪些章节
- 最终结论/核心主张（1~3 条）
- 贯穿全书的关键概念清单
- 主线中出现、但成稿可舍弃的次要分支（列出并说明理由）

约束：只使用各章摘要中已有的信息；前后矛盾处标注出来，不要自行抹平。
```

## 3. 总稿整合（口播精读稿）

### 固定框架（顺序不可调换）
1. **书籍基础卡片**：书名、作者、译者（如有）、版本信息、全书定位、目标受众、素材来源汇总；标注整体情绪倾向（正向/中性/负向/混合）。
2. **全书核心主线**：一句话主旨；3~5 个最高层级核心观点，全部锚定章节摘要，不新增无依据推论。
3. **分章节完整梳理**：按原书顺序排布各章节合并摘要，沿用四段式；保留来源标记、金句、【存疑】、【逻辑断点】；正负向评价穿插对应放置，不过滤负面视角。
4. **综合争议与评价汇总**：归集作者局限、读者好评点、质疑/批评点，每条绑定情绪标签与来源；客观陈列，不做孰对孰错的定论。
5. **收尾总结**：串联全书逻辑，说明适合谁看、能解决哪类问题；仅基于素材归纳，不拔高不贬低。

### 篇幅与语速基准
- 标准旁白语速 **220 字/分钟**；
- 目标黄金区间 **1760~1980 字（8~9 分钟）**；硬性上限 **2500 字（约 11 分 22 秒）**；
- 时间分配指引（非强制）：基础卡片 30~45 秒；核心主线 60~90 秒；分章梳理 5~6 分钟；争议汇总 60~90 秒；收尾 30~60 秒。

### 取舍优先级（精简时按顺序让步）
- **P0 必保**：全书主线、每章核心论点、关键金句、核心争议点、来源标记；
- **P1 优先压缩**：次要案例修饰、重复同义表述、过渡铺垫；
- **P2 最后取舍**：补充性旁支细节、非核心次要案例。
- 正负评价配比以素材真实占比为准，不强行拉平、不硬补对立观点；【存疑】【逻辑断点】完整保留，不在整合阶段抹平；扩量只能从已采集一级来源补充，禁止外部脑补；过渡句简短自然，不独立生成新观点。

### 输出格式
1. **正文旁白稿**：最终配音文稿，流畅串联，符合语速标准；内部保留极简锚点标记供后续配图分镜。
2. **配套附录**：完整来源清单（链接、类型、情绪标签）；金句索引（定位章节/块编号）；存疑项与逻辑断点汇总；预估总时长、实际字数、语速基准。
3. **顶层元卡片**：书名、作者、译者、版本、采集时间、路线标记（A/B/混合）、**【内容范围】（全书 / 指定章节编号与标题；系列视频标注集号）**、受众标签、整体情绪标签。范围边界规则见 `scope-boundary.md`。
4. **自检**：生成后自动核对是否突破 2500 字上限、P0 项是否全部留存、标记是否完整继承；不通过则二次微调直至达标。

### 成稿提示词模板

```
你是一名知识类精读撰稿人。基于以下章节摘要与主线，写一篇 {{目标时长，如 8~9 分钟}} 口播精读稿：

【章节摘要与主线】
{{chapter_summaries_and_main_synopsis}}

要求：
- 内容范围：{{范围：全书 / 第 X 章 / 第 X、Y 章}}；只在已确认范围内提炼，未选定章节的观点、案例、金句不得写入；
- 按固定五模块顺序组织：基础卡片 → 核心主线 → 分章梳理 → 争议评价汇总 → 收尾总结；
- 口吻：{{口吻}}，面向{{受众}}；句子短，适合朗读，避免长定语和书面嵌套；
- 篇幅：目标 1760~1980 字，上限 2500 字（220 字/分钟）；
- 保留来源标记、金句、存疑与逻辑断点；正负评价如实呈现；
- 只保留主线相关内容，不确定或素材未覆盖的点写成「存疑待核」，不要编造。

输出：顶层元卡片 → 正文旁白稿（分段，每段一个意群）→ 配套附录（来源清单/金句索引/存疑与断点/时长字数）。
```

## 4. 事实校验

```
你是一名事实核查编辑。请对照原始素材，核查下面这篇精读稿：

【原始素材】
{{source_material}}

【待核查成稿】
{{draft}}

逐条输出核查结果：
- 观点/案例/数据/金句 → 是否能在素材中找到依据（命中/未命中/部分命中）；
- 未命中项：给出处理建议（删除 / 改为存疑标注 / 补充依据）；
- 是否存在把解读者引申当成作者原意的情况；
- 结构与时长是否达标；列出需要修改的具体句子。

约束：拿不准的一律标「存疑」，不得为了通顺而放行。
```

## 5. 可变参数

| 参数 | 取值示例 | 默认 |
|---|---|---|
| 目标时长 | 8 / 9 / 10 分钟 | 8~9 分钟（上限约 11.5 分钟） |
| 语速 wpm | 200 / 220 / 250 | 220 |
| 字数上限 | 1980 / 2200 / 2500 | 2500 字 |
| 口吻 | 平实亲切、理性克制、轻松吐槽、学院派 | 平实亲切 |
| 受众 | 学生、职场人、家长、泛知识读者 | 泛知识读者 |
| 内容范围 | 全书 / 指定单章 / 指定多章 | 全书（用户明确指定时才局部） |
| 重点数量 | 3 / 5 | 3~5 |
| 输出形态 | 纯文字稿、图文笔记、短视频口播稿 | 口播稿 |
